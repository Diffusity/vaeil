## What to build

An admitted participant can send a Message, inspect its Withheld status, explicitly submit a technical-Withheld attempt for human review, and read only delivered Messages in their Conversation. An Admin can release/discard queued Messages through an authenticated API. Minimal sender/recipient UI verifies the path; full Admin console remains T9.

- [ ] Baseline without a validated model: technical Withheld with retry, no recipient delivery. Clean scanning cannot approve safety. Explicit sender submission enables human review; only audited Admin release delivers. No fake Approved adapter selectable through production config/HTTP.
- [ ] Distinguish technical failure/timeout/unreachable/busy/malformed (retry) from review-required (under review, no same-text resend). Model NeedsReview queues automatically; technical Withheld requires explicit submission. Repeated submissions are idempotent. Exact comparison/request interfaces require seam approval before tests.
- [ ] Preserve optional-port fake tests: clean+Approved -> Delivered; pre-Reveal identifier+Approved -> Escalated, delivered once, queued and audited; after Reveal -> Delivered without identifier escalation, safety still required. NeedsReview stays undelivered. Model cannot clear scanner reasons or create Reject. Human release is not labelled model approval.
- [ ] Admin release/discard is terminal and audited atomically. Release rechecks current Conversation/participant/Block/Reveal state; identifier-bearing pre-Reveal release still Escalates. Repeated/conflicting decisions never duplicate delivery/audit. Discard never delivers.
- [ ] Reload admitted role/pair from storage; refuse nonparticipants, forged actor/Reveal inputs, blocked sends/releases. Cross-Conversation state is isolated. Revealed chat continues until Block. T11 owns public Block API; T7 uses persisted blocked fixtures.

Authorized Admin review loads necessary content from the canonical record. Safe logs/errors/export, canaries and exact unwrap allowlist remain; no new unwrap planned.

- [ ] Inject Clock at actual delivery; Delivered/Escalated human releases count once for T8, Withheld never counts. Later release receives delivery time then. T8 owns eligibility/consent.
- [ ] Authenticated HTTP/minimal Conversation UI: checking, technical retry, explicit submit-for-review, under-review, recipient delivered-only history. Real-API browser test proves no delivery before review and exactly one after authorized release. Render untrusted text as text. T9 console and later H3 presentation are not prerequisites.
